# Link Gallery

Private web gallery for organizing external image URLs. Images are loaded directly from their original URLs and are never copied into this application.

## Development

1. Copy `.env.example` to `.env.local` and provide Supabase values.
2. Run `npm install`.
3. Run `npm run dev`.

## Checks

Run `npm run lint`, `npm run test`, `npm run build`, and `npm run test:e2e` before deployment.
